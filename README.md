# Mohamed Asif M — Portfolio

A responsive personal portfolio built with HTML, CSS and a small amount of vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

For local development, you can also run a simple server from this folder:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Personalise before publishing
- Add your actual LinkedIn and GitHub profile URLs if you want social links displayed.
- Add live project/demo/repository links when available.
- Replace the two photos in `assets/images/` if you prefer other portraits.
